# vSphere IP Validator

自动化脚本：通过 vCenter API 获取虚拟机清单，结合网络扫描（Ping / 端口探测）与 NetBox IPAM 数据比对，自动同步 IP 地址状态，减少人工维护 IPAM 的工作量。

## 解决的问题

企业内网的 IPAM（NetBox）数据往往会随着虚机的创建、下线、重命名逐渐失真：僵尸 IP 得不到及时标记，非虚机存活的设备（网络设备、物理机等）又不在 IPAM 记录中。本脚本每天定时运行，用多种信号交叉验证 IP 的真实状态，自动完成 NetBox 记录的创建与更新，让 IPAM 数据保持接近实时。

## 架构设计

脚本分三个阶段顺序执行，每阶段完成后落地状态标志（`state/sN.flag`），后续阶段会检查上一阶段是否在 24 小时内完成，避免因为某一阶段异常而继续污染数据：

```
┌─────────────────────┐     ┌──────────────────────┐     ┌─────────────────────┐
│  阶段1：vSphere同步   │ --> │  阶段2：全网段Ping扫描  │ --> │  阶段3：端口扫描      │
│  遍历虚机清单，从虚机  │     │  排除内网管理段后，对   │     │  对Ping不通但疑似存活 │
│  名提取IP，按开机状态  │     │  NetBox全部网段做批量  │     │  的目标网段做TCP端口  │
│  写入NetBox status   │     │  并发Ping，标记可达性  │     │  扫描，发现存活主机   │
└─────────────────────┘     └──────────────────────┘     └─────────────────────┘
```

- **阶段1 - vSphere虚机状态同步**：连接 vCenter 拉取全部虚机及电源状态，从虚机名中用正则提取 IP（优先内网段），按 `active`（开机）/ `reserved`（关机不带日期）/ `deprecated`（关机且命名带日期，通常代表已废弃）三态写入 NetBox，并对重复 IP 做冲突检测与优先级合并。
- **阶段2 - 全网段Ping扫描**：遍历 NetBox 中的全部网段生成待扫描 IP 列表（自动排除配置的管理网段），100 并发分批 Ping，避免瞬时冲击网络设备的 ARP/CPU；对已存在的 IP 追加可达性描述，对新发现可达但不在 IPAM 中的 IP 自动创建记录。
- **阶段3 - 端口扫描**：对阶段2中 Ping 不通、但落在指定关键业务网段内的 IP，做批次化的 TCP 端口扫描（每批次限时 5 分钟、单 IP 限时 20 秒的双重超时保护），用于发现禁用 ICMP 但实际服务存活的主机。

## 关键工程实践

- **安全变更策略**：脚本只做"追加式"更新——只新增标签、只将状态标记为废弃，从不删除或覆盖已有的人工描述，降低自动化误伤生产 IPAM 数据的风险。
- **分批 + 限流**：Ping/端口扫描均采用批次处理、并发数可控、批次间强制间隔，规避大规模并发探测触发网络设备告警或 IDS 拦截。
- **多层超时保护**：端口扫描针对单端口、单 IP、单批次设置了三级超时，任一环节卡死都不会拖垫整个任务。
- **阶段化状态机**：通过 flag 文件记录各阶段完成时间，24 小时内视为有效，跳过重复执行，同时保证阶段间的数据依赖关系正确。
- **配置与代码分离**：所有环境相关信息（vCenter 地址、NetBox Token、目标网段）通过 `.env` 注入，代码本身不包含任何环境特定信息。

## 环境要求

- Python 3.6+
- vCenter / ESXi 环境，具备只读 API 权限的服务账号
- NetBox（已配置好网段 Prefix）

## 安装

```bash
git clone <your-repo-url>
cd vsphere-ip-validator
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# 编辑 .env，填入实际的 vCenter / NetBox 连接信息
```

## 使用

```bash
python validator.py
```

日志输出到 `logs/vsphere_validator/validator.log`，CSV 快照保存在 `data/vsphere_validator/vsphere/`。

## 定时执行

参考 `run_cron.sh`，按需修改 `PROJECT_DIR` 后加入 crontab：

```cron
0 8,16 * * * /opt/vsphere-ip-validator/run_cron.sh
```
